## 已核实的旧稿问题

README 的闪避出现“F7–F16 无敌”与“3F 无敌启动硬线”两套起点；README 将输入缓冲写作 5–8ms，而 C04 使用逻辑帧。旧 PDF 与 README 的普攻分别为 30F 起步和 18F 起步；大招与切换规则也未统一。部分条目将调参方向写反，例如前摇调大却标为出手更快。

旧稿把“3A 使用率偏低”“镜头偶有跳变”“高压换弹几乎必被打断”等写成现阶段结论，但仓库没有支持这些结论的原型或测试记录。本次移除这些结果性表述，改成待验证问题。也移除“850m/s 为亚音速”、把 FOV 直接等同固定倍率、按角色时长推导性能的说明。
