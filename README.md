## 协作约定

1. 所有数值以 HTML 规范书为准，PDF 与 XLSX 为旧版总览，不与 HTML 冲突时可作补充引用；
2. 每份文档目录均完全自包含，含 `./assets/` 与 `./_shared/`，不允许跨目录单独拷贝文件使用；
3. 新增参数修改走 D 阶段 Before 与 After 模板记录，修改前后参数必须成对留档；
4. Bug 报告必须附带 DebugTag，前缀格式为 C02 或 C04 或 C05 或 C06，并附帧级复现步骤，分级判定见 E-01；
5. 线上热改参数必须核对 F-02 白名单，不在白名单范围内的参数必须走版本发布流程。

## 本地预览方法

每份 HTML 依赖同级 `assets/` 与 `_shared/` 两个资源目录，禁止直接双击 HTML。按以下 3 步执行：

1. 解压 `白雪公主_NIKKE动作设计_ABC阶段_配套资源包_V1.0.zip`；
2. VS Code 菜单 File → Open Folder，打开解压后的整个根目录，禁止单独 Open File；
3. 资源管理器内右键目标 HTML → Open with Live Server。

图表空白、中文方框、图片裂图，九成以上原因是未 Open 整个根目录。
