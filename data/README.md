# 参数维护与字段口径

`design.json` 保存动作、一般参数、敌人初值和验证用例。CSV 是对应的阅读与交换格式；工作簿由相同数据导出。当前未绑定引擎结构，不承诺直接导入。

- 动作：稳定 `action_id`；`total_F` 为有限动作总长；`effect_start_F / effect_end_F` 分别表示发射、补弹、近击生效区间或闪避无敌区间，须结合动作类型读取。没有该字段时为 null，CSV 留空，工作簿显示“不适用”，不能按零结算。
- `dodge_cancel_ranges_F` 为包含两端的允许区间，分号表示两段；重射的 `1-6;19-30` 表示 F6 当步可先接受闪避并撤销发射，F7–F18 不接受取消。具体迁移还要对照第 3 章，不只读取此列。
- 冷却为零表示该动作不另设冷却，不表示可以跳过总时长。闪避冷却从开始的逻辑步 t 计时，到 t+48 可再次申请。
- 蓄力与死亡的总长为空：蓄力等待玩家输入，死亡等待重开。模型动画的循环长度不决定状态长度。
- 参数值为数值类型，单位独立存放。参数约束是当前方案规则，不是行业标准。全部初值待原型试调。
- 敌人前摇、判定与后摇为同一动作的连续区间。例：近战兵 36F 前摇、F37–F42 判定、43–90F 恢复，合计 90F。普通射线只在判定起点执行一次。
- 用例：稳定 `case_id`，初始状态为“待执行”。版本、实际结果与证据须由执行者填写。文档校验不能将其改成“通过”。

工作簿的试算公式可编辑，参数格以浅黄色标记。改完参数应回写 JSON，再导出 CSV、工作簿并核对正文和图示；不要把工作簿改动当作自动回写。
